## 一、政策环境：一个改变游戏规则的文件

**发改法规〔2026〕195号《关于加快招标投标领域人工智能推广应用的实施意见》（八部门联合）**：2026年底前，招标文件检测、智能辅助评标、围串标识别全面落地；建立AI模型常态化升级机制。

对我们的三重意义：
1. **赛道政策东风**——国家层面强制推动招投标AI化，"为什么是现在"有了官方答案；
2. **新痛点制造机**——围串标识别普及后，"AI生成标书内容雷同"可能被误判为串标（阿里云开发者社区已有分析），用AI写标书的人反而产生新风险；
3. **招标文件更标准化**——全流程电子化、远程异地评标、双盲评审普及（山东2026年7月全面常态化），公告格式趋同，我们的解析引擎受益。

### 行业与出海
- 2026行业"分水岭"：销量回暖（1月挖机+49.5%）但内卷持续，涨价潮（3-5%）自救；经销商利润薄→**每一投的ROI意识增强**（就绪度评分正中）
- 出海主线：出口增速10%+，二手设备出口暴增57%（装载机），东南亚/非洲/拉美需求旺；痛点：海外询盘多语言应答、二手出口海关名录无名目/无退税

## 三、升级提案（按梯队）

### 梯队一：革命性（正中空白 + 基因延续）

**1. 商机雷达 BidRadar——从"人来找标"到"标来找人"**
把现有 analyze() 反向批量使用：监控全网新公告 → 用经销商设备库做"机型指纹匹配" → 每天推送"你能投的3个标 + 就绪度预评分"。
- 革命性：产品从**工具**变**入口**，使用频率从"投标时"变"每天"；数据飞轮（越用越懂设备库）
- 技术：现有引擎的批量化 + 公告源接入，无需新AI能力
- 一句话：别人问"这标能不能投"，我们先说"今天有这3个标你能投"

**2. 废标判例库——把"可回溯"从原文升级到判例**
全国性废标统计是空白的；判例散落在各省财政厅投诉处理公告、评审错误案例（湖南已发系列案例）。采集+结构化 → 每条风险提示附真实判例出处。
- 独创性：风控提示从"常识"变"有判例背书"，可信度维度碾压大模型话术
- 基因：反幻觉可回溯的自然延伸——回溯到司法/行政文书
- 契合195号文"招标文件检测"场景

**3. AI反雷同自检——串标误伤防火墙**
195号文围串标识别年底落地后，用AI写标书的投标人面临"内容雷同被算法误判"的新风险。做标书初稿的确定性查重：与公开标书库、自家历史标书、AI模板句式比对，给出"雷同风险分+改写建议位"。
- 时效性：政策制造的全新痛点，现在入场是第一个
- 卡位妙处：别人帮AI写标书，我们防AI标书被误杀——仍在风控生态位，不进编写红海

### 梯队二：独创（延伸价值链）

**4. 保证金与资金方案优化器**：输入公告 → 自动算"这个标最少占多少现金"（现金 vs 电子保函 vs 免收资格）+ 合同融资窗口提示。真金白银的痛点，政策红利摆渡人。

**5. 中标率校准**：用中标结果公示回测就绪度评分——"同档位设备历史中标率X%"，把主观权重变成数据校准的预测。需试点数据积累后启动。

**6. 履约回款时间线**：v2.2双清单深化——合同条款提取（账期/质保金/验收）→ 回款倒排 + 提醒 + 融资窗口。

### 梯队三：第二曲线

**7. TradePilot 出海通**（v3.0储备已有，本次调研验证）：出口+10%、二手出海57%、多语言询盘、二手出口政策真空。把"垂直+确定性+可回溯"三基因平移到外贸场景，衔接国贸专业。

## 四、优先级建议

**商机雷达 → 判例库 → 反雷同 → 资金优化器 → 中标率校准 → 履约回款 → TradePilot**

理由：商机雷达解决最高频痛点（获客）且技术上最顺（现有引擎反向用）；判例库建墙（数据资产不可复制）；反雷同抢政策时间窗。三者共同点：都从"确定性判定+可回溯+垂直语义"三条产品基因里长出来，不是追热点。
