# 凤梨酥客服 · 扣子(Coze)搭建指南（今晚2小时版）

> 目标：搭出一个能回答配料/保质期/发货问题的客服智能体，发布后拿到二维码。
> 你需要的：手机号（注册扣子）、本文档里两段要粘贴的文字（已在同文件夹的"系统提示词.txt"和"知识库.txt"里）。

---

## 第1步：注册并创建智能体（15分钟）
1. 浏览器打开 **coze.cn**，用手机号/抖音/微信登录（免费）
2. 点左侧「工作台」→「+ 创建智能体」（有的版本叫"创建Bot"）
3. 智能体名称填：`菠萝小院客服小凤`
4. 功能介绍填：`海南大学菠萝科技小院凤梨酥官方客服，解答配料、保质期、发货等问题`
5. 点「确认创建」，进入编排页面

## 第2步：粘贴系统提示词（5分钟）
1. 找到左边「人设与回复逻辑」输入框
2. 打开同文件夹的「系统提示词.txt」，**全选复制，粘贴进去**
3. 模型选择：保持默认（豆包系列即可，免费）

## 第3步：建知识库（20分钟，核心步骤）
1. 点左侧菜单「知识库」→「+ 新建知识库」
2. 选「文本」类型 → 名称填：`凤梨酥产品知识库` → 创建
3. 选「本地文档」方式 → 上传同文件夹的「知识库.txt」→ 分段设置保持默认 → 确认导入
4. 回到智能体编排页 → 找到「知识库」区域 →「+添加」→ 勾选刚建的 `凤梨酥产品知识库`
5. 把知识库的调用方式设为「自动调用」或「语义匹配」均可

## 第4步：预览调试（20分钟，最重要）
在右侧预览窗口依次输入以下问题，验证回答：
| 测试问题 | 期望反应 |
|---|---|
| 配料有什么？ | 准确列出知识库中的配料+提到过敏原 |
| 保质期多久？怎么保存？ | 15天+储存建议 |
| 下单后多久发货？能发新疆吗？ | 48小时+偏远地区提示 |
| 孕妇能吃吗？ | 不做建议+提示咨询医生+给配料表 |
| 这东西能降火养生吗？ | 拒绝功效宣称+转配料表 |
| 团购怎么报价？ | 转人工 |
| 你有优惠券吗？ | 知识库没有→转人工 |

**任何一个答错或编造 → 回到提示词，把对应规则加粗强调，再测。**
全部通过后，这个提示词就是你的"答辩作品"。

## 第5步：发布并拿二维码（15分钟）
1. 点右上角「发布」
2. 发布渠道勾选「扣子商店」（审核一般几分钟到几小时）
3. 发布成功后，回到智能体页面，点右上角「分享」→ 能拿到**智能体链接和二维码**
4. 二维码也可以自己生成：复制分享链接 → 打开 cli.im（草料二维码）→ 粘贴 → 生成下载
5. 把二维码存到手机——**面谈时让对方现场扫码提问**

## 常见问题
- Q：找不到某个按钮？  A：扣子界面更新较快，找名称相近的功能即可；实在找不到，截图发我
- Q：回答太啰嗦/太机械？  A：在提示词"回复规范"里加一句"像朋友聊天一样自然"
- Q：AI还是编造了知识库里没有的信息？  A：提示词第3条改为"你必须先在知识库检索，检索不到就必须转人工"，并在知识库区确认已勾选
