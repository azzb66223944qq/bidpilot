## 三、核心设计理念（不可违背）

1. **反幻觉铁律**：知识库里没有的一律输出"待人工核实"，绝不编造——投标场景编造=废标+法律责任
2. **确定性判定**：数值比较全部由规则引擎代码完成，绕开大模型自由发挥
3. **结论可回溯**：每个判定对应原文片段，偏离表含置信列（●高/◐中）
4. **审计日志**：每次分析自动留痕（引擎版本/输入指纹/评分），支持JSON导出
5. **★▲双级风控**：★参数负偏离=废标级，▲负偏离=评分复核级
