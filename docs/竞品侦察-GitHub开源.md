## 二、最深竞品对比：tender-review-kit vs 标书快反

| 维度 | tender-review-kit | 标书快反 |
|---|---|---|
| 产品形态 | skill包（需外接AI编程助手） | 独立网页App/PWA，零安装离线可用 |
| 输入 | PDF/Word直接解析 | 文本粘贴（PDF解析列入v2.1） |
| 核心输出 | 废标项+评分项+证明材料+▲参数+时间节点清单 | 资格自查+偏离表+风险TOP5+就绪度评分 |
| 决策建议 | **明确不下"投/不投"结论** | **评分模型+建议投标**（差异化核心） |
| ▲条款识别 | ✅ | ✅ v1.7（双方独立验证=行业惯例实锤） |
| 可追溯 | 行号出处 | 原文批注视图+审计日志+输入指纹 |
| 垂直深度 | 通用 | 工程机械32类参数7大机型族 |
| 离线 | 依赖外部Agent | 规则引擎完全离线 |

**关键洞察**：双方都认可"▲标识、行号追溯、时间节点、不编造"是行业刚需——**两条独立团队能工到同构，说明需求判断正确**。差异在最后一步：他们止步于"清单和事实"，我们给出"评分与决策建议"并承担了更难的置信度问题。

## 三、对产品的四个直接启示

1. **定位话术修正**：不说"市场空白"，说"编写型工具（OpenBidKit）解决怎么写、审标skill解决读规则，标书快反占据**投标前10秒投/不投决策风控**这一最痛环节——阶段不同，互补大于竞争"。
2. **必答题准备**："OpenBidKit免费开源，为什么用你们？"——答：编写期重型工具 vs 投前期轻量决策，阶段不同；且我们有垂直机械参数库、评分模型、离线单文件。
3. **路线图校准**：①招标要求/合同要求**双清单分离**（tender-review-kit验证过的洞察，列入v2.1）；②PDF/Word输入优先级提升（对方已打通）；③扫描件OCR可考察MinerU方案（BidMaster-Pro在用）。
4. **渠道**：阮一峰周刊收录过OpenBidKit——开源仓库打磨好后值得投稿同类周刊。

## 四、答辩防守预案

- 评委问"OpenBidKit 2.9k星，你们怎么竞争？"→ "阶段不同：它是编写期工具，我们在投前决策期；它是通用工具，我们有工程机械垂直参数库与评分模型；它免费开源，我们以离线单文件+数据本机的合规形态服务同一批客户的另一个环节。"
- 评委问"怎么证明需求真实？"→ "多个团队独立做出同构功能（▲条款、废标清单、时间节点），恰恰证明需求真实且未被垄断。"
