# 大白话版 · 一分钟搞懂标书快反

> 给完全不懂技术的队友看的，看完就能帮着说话。

---

## 它是干嘛的？

一句话：**帮工程机械经销商在投标前快速"体检"，10秒钟告诉他们这标能不能投。**

你想象一下：一个卖挖掘机的老板，想接政府的活儿，就得去"投标"。投标前他要做一堆功课——看公告要求什么、比自己设备够不够格、哪些条款容易踩雷。这些活儿靠人干要两三天，还容易漏看。漏看一条，几万块保证金就没了。

我们的产品把这些活儿压缩到10秒：把资料和公告粘进去，它自动帮你查——哪些能投、哪些不够格、哪里有坑、综合打多少分。

## 它怎么做到的？

分两层（就像医院抽血化验）：

- **机器化验**（规则引擎）：写死的程序，输入血液样本→输出指标单。快、准、离线也能用。这是我们花了最多时间的核心——32种参数自动识别、自动换算单位、逐条比对打分。
- **AI医生**（大模型）：机器出完报告后，AI再综合解读一下。但它必须遵守我们的规矩：**知识库里没有的，一个字不许编**。这是跟ChatGPT最大的区别——投标场景编一个数据就是废标+法律风险。

## 跟ChatGPT有什么区别？

ChatGPT会编数据。你问它"我的设备符不符合要求"，它可能编一个参数说"符合"——投标场景里这就废标了。

我们做了一个铁规矩：**资料库里没有的东西，它就说"不在资料库中，请核实"，绝不编造**。这就是为什么经销商敢用它。
