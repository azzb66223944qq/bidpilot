# 品类样本收集SOP · 调研担当工作手册（v1）

> 致队友：这份手册对应的工作，是把工程机械各品类的**真实采购文件**收集起来，喂给我们的AI产品当"教材"。
> 你收集的每一份参数表，都会变成产品认识这个品类的知识——期末你能在产品更新记录里看到你的贡献。
> 零代码、零技术门槛：会搜索、会下载文件、会填表格就够。预计每份有效样本15-30分钟。

---

## 一、目标（一句话）

**按品类收集含"技术参数表"的政府采购文件样本，每周5-8份，优先覆盖P1品类。**

这些样本将用于：①让AI学会识别各品类的关键参数；②为商业计划书提供真实调研数据；③作为答辩时"我们研究过真实市场"的证据。

## 三、工作流程（六步，每份样本走一遍）

### 第1步：搜索公告
- 打开中国政府采购网全文检索：
  `http://search.ccgp.gov.cn/bxsearch?searchtype=2&page_index=1&bidSort=0&pinMu=0&bidType=0&kw=压路机`
  （把kw=后面的词换成上表关键词；searchtype=2是全文检索，比标题检索命中多）
- 也可用"剑鱼标讯"App（免费注册），同样关键词订阅。

### 第2步：筛选（3问）
点开公告正文，快速判断：
1. 有没有我们要的品类？（正文搜品类词）
2. 是**采购公告**吗？（类型最好是公开招标/竞争性谈判/竞争性磋商——中标公告也留着，里面有成交价可参考）
3. 页面底部**"附件信息"**有没有PDF附件？

### 第3步：下载附件
- 公告页底部的附件PDF很可能就是**完整招标文件**（含技术参数章节）——全部下载；
- 例：青海那份公告页挂了《009（公招）第二次.pdf》，里面就有第五章技术参数。
- 打开PDF，Ctrl+F搜"技术参数"或"技术要求"或"主要技术指标"——**搜到参数表=有效样本**；只有公告页没有参数的，记"无效（未挂参数表）"。

### 第4步：登记（核心！决定你的成果能不能被用）
把以下信息填进《品类样本登记表》（表格模板已给你，Excel或文本都行）：

| 字段 | 说明 |
|---|---|
| 序号/品类/地区/发布日期 | 基本信息 |
| 项目名称+来源链接 | 必须完整，方便回溯 |
| 参数表是否命中 | 是/否（搜"技术参数"命中即"是"） |
| **摘录参数原文** | 把参数表里该品类的关键行**原样复制**5-15行（例："额定功率 ≥162kW"）——**这是最有价值的字段，宁多勿少** |
| ★条款 | 参数或条款里带★的原样摘录 |
| 特殊表述 | 任何"看起来不常见的说法"（如"接地比压""上装式"），原样记录 |

### 第5步：存档命名
PDF按 `品类-省份-项目简称-日期.pdf` 重命名（例：`压路机-青海-平安区农机-20260902.pdf`），和登记表放同一个文件夹。

### 第6步：交付
每周日晚上把当周文件夹+登记表打包发给队长。队长会反馈哪些样本"有效"，有效样本越多，下周越省力。

## 四、质量红线（务必遵守）

1. **只用公开信息**：政府采购网公告和附件本来就是公开的，正常下载没问题；但**不要用爬虫工具批量抓**，手动下载即可；
2. **保留来源**：登记表里来源链接必填——将来产品和商业计划书引用这些数据，可追溯才站得住；
3. **不贪数量**：一份"含完整参数表"的样本，顶十份空公告。搜不到就换关键词/换品类，别硬凑；
4. **个人隐私零接触**：公告里若出现个人手机号等，登记表里不要抄录。

## 五、常见问题

- **Q：政采云要注册才能下附件怎么办？** A：优先找ccgp公告页直接挂附件的（很多都挂）；政采云供应商注册需要营业执照，学生注册不了，跳过即可，样本多得是。
- **Q：参数表是扫描图片搜不了字？** A：也算有效！登记表里"摘录参数原文"填"扫描件"，PDF照样存档（队长有办法处理）。
- **Q：同一个品类的样本要多少份？** A：每个P1品类先凑5份，之后队长会喊停或换品类。

## 六、你的成果会去哪（给你动力）

每份有效样本 → 队长提取参数语义 → 写进AI判定规则库 → 产品更新记录里标注"该品类支持由调研样本驱动"。
也就是说：**这个产品的品类覆盖版图，是你一格一格铺出来的。** 商业计划书里的"市场调研数据"部分，也直接引用你的登记表统计。
