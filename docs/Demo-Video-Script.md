## 旁白与字幕建议

- 全程旁白即上表"旁白词"，语速放慢（每镜头多留1-2秒缓冲）；
- 关键数字建议加字幕强调：**10秒 / 94分A级 / 废标红条 / 6处高风险 / 142项测试**；
- 结尾定帧3秒，可叠加一行字幕："标书快反 BidPilot · 反幻觉 · 可回溯 · 双引擎"，并叠加一行网址字幕：https://azzb66223944qq.github.io/bidpilot/。

## 录制与导出

1. `Cmd+Shift+5` → "录制整个屏幕"→ 选项里选择内置麦克风；
2. 按镜头表顺序操作，每个镜头之间停顿1秒再点下一处（方便后期剪辑）；
3. 停止录制后得到 .mov，可直接用"快速时间"裁剪头尾；如需压缩：
   `ffmpeg -i 演示视频.mov -vcodec h264 -crf 26 演示视频.mp4`（未装ffmpeg可用"导出为1080p"替代）；
4. 按报名系统要求命名（如"参赛项目演示视频-标书快反.mp4"）并核对时长/大小上限。
