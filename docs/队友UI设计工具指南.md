## 一、先搞清楚我们要做什么

你不需要"学会设计"，你只需要：**把文字描述变成看得见的界面图**。AI负责画，你负责说"我要什么样的"。

我们要设计的是「标书快反」的界面——一个帮工程机械经销商分析投标文件的工具。它有几个核心页面（评分结果页/参数对比表/风险提醒），你用AI生成这几页的视觉方案就行。

## 二、工具推荐（按上手难度排序）

### 🥇 首选：Motiff 妙多（AI原生UI设计，最适合我们）

**它是啥**：专门做UI设计的AI工具——你打字描述"我要一个深色主题的数据面板"，它直接生成可编辑的界面稿。

**怎么访问**：
1. 浏览器打开 **miaoduo.com**（国内版入口）
2. 手机号注册（免费）
3. 点「新建文件」→ 进入编辑器

**怎么用（3步出图）**：
1. 在画布上找到「AI工具箱」或「AI生成」按钮
2. 输入描述，例如：
   ```
   生成一个深色主题的投标分析仪表盘，包含：左侧窄导航栏（图标式）、
   顶部大评分环显示94分、下方网格卡片展示技术参数对比表格，
   风格参考Linear.app，色调深蓝+青绿点缀
   ```
3. 等几秒 → AI生成界面 → 你可以继续用文字让它改（"把评分环改成渐变色""表格行高增加"）

**免费额度**：AI功能公测免费，含500次AI工具箱使用权限——够你折腾了。

**导出**：选中画板 → 右键导出PNG → 发群里就能讨论。

---

### 🥈 备选：即时设计（国产Figma，资源最全）

**它是啥**：在线UI设计工具（类似Figma但全中文），有海量现成模板+AI插件。

**怎么访问**：
1. 浏览器打开 **js.design**
2. 微信扫码登录（免费）

**怎么用（模板改造法，比从零画更快）**：
1. 首页搜索「仪表盘」「dashboard」「数据分析」
2. 挑一个喜欢的模板 → 点「使用」
3. 在模板上改文字（双击编辑）："营收"改成"就绪度评分"、"用户数"改成"满足项数"……
4. 改配色：选中元素 → 右侧颜色面板换成我们的主题色
5. 导出PNG

**什么时候选它**：想快速出多个配色方案（模板改字比AI生成更可控）。

### 🥉 氛围图利器：堆友 / Tripo（AI生图，做风格探索）

**它是啥**：AI生图工具（类似Midjourney但国内直连、免费额度足），不生成可编辑UI，但能快速出"风格氛围图"。

**怎么访问**：
- 堆友：浏览器打开 **d.design** → 微信登录
- 免费额度每天签到送，够用

**怎么用**：
输入描述词，例如：
```
深色科技感数据分析仪表盘UI，左侧窄导航，中央大圆环图表显示94分，
青绿色高亮，网格卡片布局，Linear风格，界面设计，高清
```

**用途**：快速生成10种不同风格的氛围图，发群里投票选方向——比逐个做原型快100倍。

---

### 加分项：讯飞智文 / Kimi（AI写文案描述）

如果你不知道怎么向设计工具描述需求，先问AI：
- 打开 **kimi.com**（月之暗面，免费）
- 输入："帮我把这段需求翻译成UI设计描述：我想让投标分析工具的界面看起来很专业很可靠，主色是深蓝色，要有评分圆环和参数表格……"
- Kimi会帮你润色成更精准的设计描述词

## 三、推荐的作业流程（给队友的具体任务）

### 第一步：风格探索（用堆友，30分钟）
1. 用AI生图生成**6种不同风格**的氛围图（深色科技/亮色商务/渐变现代/纸质极简/便当网格/终端极客）
2. 每种风格2-3张，导出后发到群里投票

### 第二步：出高保真方案（用Motiff，2小时）
1. 根据群里投票最高的风格，在Motiff里用AI生成完整界面
2. 核心页面做3张：**①评分结果页 ②技术偏离表页 ③废标风险页**
3. 每张导出PNG

### 第三步：配色变体（用即时设计，30分钟）
1. 把Motiff导出的方案导入即时设计
2. 复制3份，分别换3套配色（深蓝+青 / 绿+金 / 黑+绿）
3. 全部导出发群

### 交付物
- 3个核心页面 × 3套配色 = **9张PNG**
- 发到群里，配一句话说明每个方案的定位

## 四、描述词模板（直接复制改用）

**生成仪表盘**：
```
[深色/亮色]主题的[行业]数据分析仪表盘，包含[具体组件列表]，
风格参考[Linear/Stripe/Notion]，主色调[颜色]，字体[现代无衬线/中文黑体]，
界面干净专业，[分辨率]，UI设计
```

**改配色**：
```
保持布局不变，把主色从[X]换成[Y]，强调色用[Z]，背景色[A]
```

**生成移动端**：
```
把上述设计适配到手机屏幕，375px宽，底部Tab导航，卡片纵向排列
```

## 五、遇到问题怎么办

| 问题 | 解决 |
|---|---|
| Motiff AI生成的不满意 | 用"继续修改"功能，告诉它具体哪里不对（"间距太大""颜色太暗"） |
| 不知道选什么风格 | 先去 **godashboarddesign.com** 或 Dribbble 搜"dashboard"看灵感 |
| 免费额度用完了 | 换另一个工具继续（我们推荐了3个备选） |
| 导出的图不够清晰 | 导出时选2x或3x倍率 |
