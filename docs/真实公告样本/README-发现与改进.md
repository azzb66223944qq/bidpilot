# 真实公告样本 · 实测发现与改进记录

> 样本来源：中国政府采购网（ccgp.gov.cn），2026年9月抓取，共4份（均含装载机，2份含挖掘机）。
> 用途：产品测试与学习样本；权利归原发布机构。

## 实测发现的3个真实差距（均已转化为产品改进）

### 1. 「采购预算」≠「最高限价」（高危误提取，已修复）
真实公告大多只写"预算金额"，不写"最高限价"。原引擎把预算当限价提取，会导致业务员按错误的报价上限做策略（如把2725万项目总预算当成单台装载机限价）。
**修复**：预算与限价分离为两个字段；限价仅认"最高限价/上限价"等明确表述。速览卡与HTML报告分别显示。

### 2. 「最高限价（元）：3783217.78」格式（漏提取，已修复）
政府采购网的规范写法是"字段（元）：数字"，单位在括号内、数字在后，与常见的"35.8万元"相反。
**修复**：金额提取兼容两种格式；新增4项回归断言锁定。

### 3. 技术参数不在公告里（工作流认知，非缺陷）
真实公告的参数表一律写"详见采购文件"——参数在报名后下载的采购文件附件中。
**正确工作流**：公告阶段先跑资格自查+行动时间表（引擎已支持）；拿到采购文件后，把第四章参数贴入再生成偏离表。这验证了产品的两阶段设计是符合真实业务的。
